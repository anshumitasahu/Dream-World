# Dream World

Dream World is an interactive 3D web experience where you can explore different dream-like environments.

The project is built with **React, Three.js, and React Three Fiber**, using 3D `.glb` models to create the world.

### What I'm Building

* 3D environments made from reusable models
* First-person movement and exploration
* Different objects and scenes that can be placed dynamically
* A system for turning ideas into unique dream worlds
* A place to save and share created worlds

This is a project I'm building while learning **3D web development, React Three Fiber, and backend development**.
